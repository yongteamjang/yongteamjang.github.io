세 가지가 뭔가요

셋 다 오픈AI가 챗GPT 데스크톱 앱에 넣은 기능이에요. 원래는 개발자가 앱을 고치고 화면에서 확인하라고 만든 기능인데, 판매자센터 확인·엑셀 정리처럼 버튼을 눌러야 하는 일에도 써요.

돌아가는 순서

  1. 컴퓨터 사용(Computer Use): 앱에 맥의 '화면 기록'과 '손쉬운 사용' 권한을 주면, 챗GPT가 화면을 찍어 보고 마우스·키보드를 움직여요. 처음 쓰는 앱은 매번 허락을 물어요.
  2. 브라우저(Browser): 챗GPT 안에 있는 따로 된 브라우저예요. 내 크롬과 로그인·탭을 공유하지 않아요. 내 크롬을 그대로 쓰려면 크롬 확장 프로그램을 깔아요.
  3. 연결(Connections): 컴퓨터 화면의 QR 코드를 폰으로 찍어 짝을 지어요. 그 뒤엔 폰에서 보낸 요청을 컴퓨터가 받아서 해요.

릴스에서 말한 것

  • "설정에서 컴퓨터 사용을 누르세요": 맞아요. 다만 먼저 앱 위쪽에서 Work(또는 Codex)로 바꿔야 보여요. 공식 메뉴는 Settings(설정) > Computer use(컴퓨터 사용)이고, Control(제어) 아래 Any App(모든 앱)을 켜는 구조예요.
  • "크롬, 사파리, 엑셀처럼 쓰는 앱만 켜 주세요": 크롬·엑셀은 따로 칸이 있어요. 크롬은 확장 프로그램을 깔아야 하고, 크롬 칸 스위치는 @ 메뉴에 보일지만 정해요. 사파리는 공식 확장 지원 목록(크롬·엣지·브레이브·오페라·비발디)에 없어서 Any App으로 다뤄요. 사파리 전용 칸은 확인 못 했어요.
  • "켜 둔 앱을 챗GPT가 직접 다뤄요": 허락한 앱만 다뤄요. 켜 둬도 작업 중에 앱마다 허락 창이 뜨고, '항상 허용'을 누른 앱만 다음부터 안 물어요.
  • "그 아래 브라우저 기능을 켜고": 설정 > 브라우저(Browser)에서 내장 브라우저를 켜요. 릴스 화면의 '로그인 상태 유지'·'작업 시간 제한' 칸은 공식 문서에서 확인 못 했어요.
  • "에이전트 권한을 항상 허용으로": 공식 화면은 칸이 셋이에요. 둘러보기(Browse)·다운로드(Download)·업로드(Upload)마다 '승인 필요 / 항상 허용 / 차단'을 고르고, 사이트별 예외를 둬요. 오픈AI는 클라우드 브라우저의 '항상 허용'을 "권하지 않는다"고 적었어요.
  • "사이트 들어가서 하는 일도 맡길 수 있어요": 사이트를 열고 누르고 입력해요. 단, 정보 제출·구매·권한 변경·삭제 전엔 '항상 허용'이어도 확인을 물어요. 내장 브라우저에선 파일 올리기를 자동으로 못 하고, 자동 접속을 막는 사이트·캡차(사람인지 묻는 그림 문제)가 있으면 멈춰요.
  • "결제, 삭제, 전송은 꼭 직접 확인하세요": 공식 안내와 같아요. 계정·보안·결제·로그인 정보 설정 때는 자리에 있으라고 적혀 있어요.
  • "설정에서 연결을 누르고 내 핸드폰과 연결": 공식 순서는 설정 > 연결(Connections) > Control this Mac or PC(이 맥·PC 제어) > 설정(Set up) → 화면의 QR 코드를 폰으로 찍기예요. 아이폰 앱에선 'Codex'(예전 이름 'Remote') 메뉴에 컴퓨터가 떠요. 안드로이드도 돼요.
  • "이 컴퓨터를 제어할 수 있는 기기로 켜 주세요": 같은 연결 화면에서 '컴퓨터 깨어 있게 두기', '컴퓨터 사용 켜기', '크롬 확장 설치'도 고를 수 있어요. 릴스 속 글자는 다시 그린 화면이라 실제 이름과 조금 달라요.
  • "컴퓨터만 켜져 있으면 밖에서도": 조건이 더 있어요. 컴퓨터가 잠들지 않고, 인터넷에 붙어 있고, 챗GPT 앱이 켜져 같은 계정으로 로그인돼 있어야 해요. 맥 노트북은 덮개를 닫으면 외부 모니터가 있어야 하고, 윈도우는 잠금 해제 상태여야 해요.
  • "아무 댓글 → DM으로 정리본": 릴스 속 'A~Z 가이드북' 카드는 설명하려고 만든 예시 화면이에요. 실제로 보내는 자료는 이 페이지예요.

돈은 얼마나 드나요

  • 따로 내는 돈은 없어요. 세 기능 모두 챗GPT 플랜 사용량 안에서 써요(챗GPT Work·Codex 요금표).
  • 플랜별: Plus 월 $20, Pro 월 $100·$200·$500, Business 사용자당 월 $20(2명 이상·연간 결제, 월 결제면 $25). Free($0)·Go(월 $8)는 요금표 기능 표에 컴퓨터 사용·휴대폰 원격 칸이 없어요.
  • 컴퓨터 사용·크롬 제어: Plus·Pro·Business·Enterprise 모두 '제한적(limited)'이고, 사유가 '지역(region)'으로 표시돼 있어요. 한국이 되는지는 공식 나라 목록이 없어서 확인 못 했어요 → 내 앱에 메뉴가 보이면 되는 거예요.
  • 휴대폰 원격 제어: Plus·Pro·Business·Enterprise에서 '사용 가능'이에요.
  • 늘어나는 조건: 화면을 찍어 보고 판단하는 작업은 사용량을 더 써요. 한도에 걸리면 크레딧을 사서 늘릴 수 있어요(Plus·Pro).

세 가지 켜는 법

아래 메뉴 이름은 오픈AI 영어 문서 기준이에요. 한국어 화면에선 '설정 › 컴퓨터 사용 › 모든 앱'처럼 우리말로 보여요. 이름이 조금 달라도 위치는 같아요.

시작 전에: 앱 최신으로

  1. 챗GPT 데스크톱 앱을 열고 업데이트 확인을 눌러 최신으로 올려요. 폰 챗GPT 앱도 최신으로.
  2. 앱 위쪽에서 Work로 바꿔요. 컴퓨터 사용 메뉴는 Work나 Codex에서만 보여요.
  3. 설정은 맥에서 Cmd+,, 윈도우에서 Ctrl+,로 열려요.

01 컴퓨터 사용

  1. 설정 > 컴퓨터 사용(Computer use)을 눌러요.
  2. Control(제어) 아래 Any App(모든 앱) 줄을 봐요. '설치(Install)'가 보이면 누르고 안내대로, 스위치가 꺼져 있으면 켜요.
  3. 맥이면 권한 창이 떠요. 시스템 설정 > 개인정보 보호 및 보안에서 화면 기록과 손쉬운 사용을 'Codex Computer Use'에 켜 줘요. 화면 기록은 보는 데, 손쉬운 사용은 누르고 입력하는 데 필요해요.
  4. 크롬을 쓰려면 같은 화면 크롬 줄의 설치(Install) → 크롬 웹스토어에서 챗GPT 확장 프로그램 설치 → 돌아와서 크롬 줄이 관리(Manage)로 바뀌었는지 봐요.
  5. 엑셀은 엑셀 줄을 켜요. 그 밖의 앱은 Any App으로 다뤄요.

02 브라우저

  1. 설정 > 브라우저(Browser)를 눌러요. 내장 브라우저가 꺼져 있으면 설치·켜기를 해요.
  2. Agent permissions(에이전트 권한)에서 세 칸을 정해요. 처음엔 이렇게 권해요: 둘러보기 = 항상 허용, 다운로드 = 승인 필요, 업로드 = 승인 필요.
  3. 자주 쓰는 사이트(예: 스마트스토어센터)만 예외로 추가해서 '항상 허용'을 줘요. 모르는 사이트까지 다 열어 두지 마세요.
  4. 사이트별 설정을 지우면 기본값으로 돌아가요.

03 연결

  1. 컴퓨터에서 설정 > 연결(Connections) > Control this Mac or PC(이 맥·PC 제어) > 설정(Set up) 또는 추가(Add)를 눌러요.
  2. 원격 접속을 승인하고, 본인 확인(2단계 인증 등)을 끝내요.
  3. 화면에 뜬 QR 코드를 폰 카메라로 찍어요. 챗GPT 폰 앱이 열려요.
  4. 폰에서 같은 계정·같은 워크스페이스인지 확인하고 마쳐요. 아이폰은 'Codex'(예전 앱은 'Remote') 메뉴에 컴퓨터가 떠요.
  5. 컴퓨터 연결 화면에서 컴퓨터 깨어 있게 두기를 켜요. 회사 워크스페이스면 관리자가 '원격 제어'를 먼저 허용해야 할 수 있어요.

내 일로 짧게 해 보기 · 오늘 주문 정리

릴스에서 말한 "밖에서도 폰으로 일 시키기"를 스마트스토어 주문 확인으로 끝까지 해 봐요. 읽기만 하는 일로 시작해요.

  1. 컴퓨터에서 크롬을 열고 스마트스토어센터에 미리 로그인해 둬요. 비밀번호는 챗GPT에게 주지 않아요.
  2. 컴퓨터에서 챗GPT 앱을 Work로 두고, 폰과 연결된 상태로 그대로 둬요(잠자기 X).
  3. 폰에서 챗GPT 앱 → Codex(또는 Remote) → 내 컴퓨터를 고르고 새 대화를 열어 아래를 붙여 넣어요.

@Chrome 로 이미 로그인된 스마트스토어센터를 열어서 [오늘] 들어온 신규 주문을 확인해 줘.

3. 로그인 창이 나오면 멈추고 나한테 말해. 비밀번호는 내가 직접 넣을게.

  1. 보이는 화면: 폰에 "크롬을 써도 될까요?" 같은 허락 요청이 와요 → 처음엔 한 번만 허용.
  2. 챗GPT가 판매자센터를 읽는 동안 폰에서 진행 상황과 스크린샷을 볼 수 있어요. 끝나면 알림이 와요.

읽기가 잘 되면 엑셀 정리로 넘어가요. 이번엔 쓰기라 꼭 바뀔 내용을 먼저 보여 달라고 해요.

2. 원래 시트는 건드리지 마.
3. 바꾸기 전에 무엇을 추가하는지 먼저 보여 주고, 내가 '좋아'라고 하면 저장해.

조심할 점

  • 결과는 초안이에요. 화면을 보고 읽은 숫자라 틀릴 수 있어요. 주문·금액은 원래 화면과 대조하세요.
  • 로그인된 사이트는 내 계정으로 움직여요. 챗GPT가 누른 버튼은 사이트 입장에선 내가 누른 거예요. 판매자센터에선 처음 몇 번은 옆에서 지켜보세요.
  • 웹페이지 글을 믿지 마세요. 사이트 안에 "이 버튼을 누르세요" 같은 속이는 글이 있을 수 있어요. 사이트를 허용해도 그 사이트 내용까지 믿을 만해지는 건 아니에요.
  • 내 화면이 어디로 가나요: 컴퓨터 사용이 찍은 스크린샷도 챗GPT 데이터 설정(설정 > 데이터 제어)을 따라요. 작업에 필요 없는 메신저·사진·은행 앱은 닫아 두세요.
  • 항상 허용은 믿는 앱·사이트에만. 앱은 설정 > 컴퓨터 사용 > 항상 허용 목록에서 언제든 빼요.
  • 못 하는 것: 터미널(명령어 치는 까만 창)과 챗GPT 자기 자신은 조작 못 해요. 관리자 비밀번호 입력이나 보안·개인정보 권한 창 승인도 못 해요 → 내가 해요.
  • 윈도우는 화면을 가져가요. 작업하는 동안 마우스·키보드를 챗GPT가 써요. 맥은 뒤에서 돌릴 수 있어요.
  • 회사 계정(Business·Enterprise)이면 관리자가 컴퓨터 사용·사이트·앱·원격 제어를 막거나 고를 수 있어요. 메뉴가 안 보이면 관리자에게 먼저 물어보세요.
  • 한국어: 요청은 한국어로 해도 돼요(이 페이지 요청문 그대로). 메뉴 이름은 앱 언어 설정에 따라 영어로 보일 수 있어요.

막힐 때

  • 설정에 '컴퓨터 사용'이 없어요 → 앱 위쪽을 Work로 바꿨는지, 앱이 최신인지, 플랜이 Plus 이상인지 봐요. 그래도 없으면 지역 제한일 수 있어요. 아래 글을 챗GPT에 물어보세요.
  • 앱이 안 보이거나 눌리지 않아요(맥) → 시스템 설정 > 개인정보 보호 및 보안 > 화면 기록·손쉬운 사용에서 'Codex Computer Use'가 켜져 있는지 봐요. 켠 뒤 챗GPT 앱을 다시 시작해요.
  • 크롬을 @로 못 불러요 → 컴퓨터 사용 화면 크롬 줄이 '관리(Manage)'인지, 확장 프로그램을 깐 그 크롬 프로필로 열었는지 봐요.
  • 폰에 내 컴퓨터가 안 떠요 → 컴퓨터가 잠들었거나 앱이 꺼졌어요. 두 앱 다 최신으로 올리고 같은 계정·워크스페이스인지 본 뒤 QR로 다시 짝지어요(6월 8일 이후 안 쓴 연결은 다시 짝지어야 해요).
  • 사이트에서 멈췄어요 → 캡차·자동 접속 차단이에요. 그 단계만 내가 하고 "이어서 해 줘"라고 해요.
  • 엉뚱한 창을 눌러요 → 바로 작업을 멈추고(중지), 요청에 앱 이름과 창 이름을 더 정확히 적어요.
  • 그래도 안 되면 → 용팀장 단톡방(오픈채팅방)에 내 화면을 캡처해서 올려 주세요.
