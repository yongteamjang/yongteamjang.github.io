마크잇다운으로 먼저

공급사 카탈로그 PDF를 글로 바꿔서, 필요한 것만 표로 뽑는 순서예요. 릴스 「클로드에 PDF, 그냥 올리지 마세요」 정리본입니다.

왜 바꾸나설치변환요청 문장대조 체크용팀장 단톡방

PDF를 그대로 올리면 생기는 일

PDF를 올리면 클로드는 글만 읽지 않아요. 페이지 배치, 사진, 머리말, 빈 표 칸까지 같이 처리합니다. 카탈로그처럼 쪽수가 많을수록 토큰을 더 쓰고, 정작 필요한 단가나 금지 문구를 놓칠 수 있어요.

  1. 공급사 카탈로그.pdf
  2. 마크잇다운으로 변환
    마이크로소프트가 공개한 도구. PDF, 워드, 파워포인트, 엑셀을 AI가 읽기 편한 마크다운 글로 바꿔 줘요
  3. 글만 남은 카탈로그.md
    제목과 표가 글로 정리돼 있어서 클로드가 바로 알아봐요
  4. 클로드가 필요한 것만 표로

변환한 글과 클로드가 만든 표는 초안이에요. 원본이랑 한 번 대조하는 건 사람 몫입니다.

설치는 한 줄

맥은 '터미널', 윈도우는 'PowerShell'을 열고 붙여 넣으세요.

1. 파이썬 버전 확인

python3 --version

3.10 이상이어야 설치돼요. 맥 기본 파이썬은 3.9인 경우가 있어서, 그러면 python.org에서 새 버전을 먼저 받으세요.

2. 마크잇다운 설치

pip install 'markitdown[all]'

윈도우에서 따옴표 때문에 막히면 pip install "markitdown[all]"로 바꿔 보세요.

터미널이 낯설면 · 클로드코드에 이렇게

내 컴퓨터에 마이크로소프트 마크잇다운(markitdown)을 설치해 줘. 파이썬 버전이 낮으면 먼저 알려 주고, 설치가 끝나면 잘 됐는지 확인까지 해 줘.

파일 종류별 변환 명령어 4줄

파일이 있는 폴더에서 실행하세요. 앞이 원본 파일, -o 뒤가 새로 만들어질 .md 파일이에요.

변환 명령어

markitdown 카탈로그.pdf -o 카탈로그.md
markitdown 견적서.docx -o 견적서.md
markitdown 상품소개.pptx -o 상품소개.md
markitdown 단가표.xlsx -o 단가표.md

변환하고 바로 열어 보세요. 사진으로 찍어서 만든 스캔본 PDF는 글자가 거의 안 나올 수 있어요. .md 파일에 글자가 비어 있으면 그 PDF는 이 방법이 안 맞는 파일입니다.

클로드코드에 시킬 때

이 폴더에 있는 PDF를 전부 마크잇다운으로 .md 파일로 바꿔 줘. 끝나면 파일마다 글자가 제대로 나왔는지 알려 줘.

카탈로그 요청 문장

변환한 카탈로그.md를 클로드에 올리고 그대로 붙여 넣으세요.

요청 문장 원문

첨부한 공급사 카탈로그에서 아래 두 가지만 표로 뽑아 줘.
1. 판매 금지 문구: 상품명이나 상세페이지에 쓰면 안 된다고 적힌 문구를 원문 그대로, 몇 쪽에 있었는지와 같이.
2. 옵션별 단가: 상품명, 옵션명, 단가, 최소 주문 수량, 통화 단위.
카탈로그에 없는 내용은 지어내지 말고 '없음'이라고 써 줘. 숫자가 애매하면 추측하지 말고 '확인 필요'라고 표시해 줘.

표가 나오면 "이 표를 엑셀 파일로 만들어 줘"라고 이어서 말하면 다음 상품 등록 때 바로 씁니다.

원본이랑 대조하는 체크 5가지

AI도 새는 게 있어서, 사람이 한 번 더 거릅니다.

하나라도 걸리면 그 줄은 원본 숫자로 고쳐서 쓰세요. 틀린 단가로 등록하면 마진이 어긋나고, 빠진 금지 문구는 판매중지로 돌아올 수 있어요.

AI는 초안, 판단은 사람입니다. 마크잇다운이 글로 바꾸고, 클로드가 표 초안을 만들고, 사람이 원본이랑 대조해서 씁니다.
